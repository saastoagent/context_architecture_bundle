# Docs

Use this folder for user, operator, and developer guides.

Docs should answer how to use the system. Architecture ownership belongs in
`architecture/`, validation meaning belongs in `test_index/`, and current state
belongs in `context.md`.

Suggested docs:

- `setup.md`
- `usage.md`
- `debugging.md`
- `deployment.md`
- `api-reference.md`
