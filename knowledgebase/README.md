# Knowledgebase

Use this folder for verified reusable findings and patterns.

Good entries:

- repeatable debugging patterns
- integration constraints proven from source
- external research that affects implementation choices
- product/domain rules that recur across features

Bad entries:

- one-off session summaries
- unverified guesses
- stale code descriptions
- information that belongs in `context.md`, `architecture/`, or `test_index/`
